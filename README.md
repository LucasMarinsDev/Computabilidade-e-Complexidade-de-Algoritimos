# Computabilidade-e-Complexidade-de-Algoritimos
Sistema de rotas inteligentes (Atlas Global) para artigo científico em Computabilidade e Complexidade de Algoritmos. Estuda e otimiza o algoritmo de Dijkstra para cálculo de caminhos mínimos em grafos, comparando estruturas de dados (heap binário, fila de prioridade) quanto a desempenho e escalabilidade.
