# Atlas Global — Sistema Inteligente de Rotas

## Objetivo

Desenvolver um sistema inteligente de rotas utilizando conceitos de Teoria dos Grafos e algoritmos de busca de caminhos.

## Descrição

O Atlas Global é um projeto desenvolvido para aplicar conceitos de Teoria dos Grafos na representação e análise de rotas, utilizando algoritmos para auxiliar na identificação de caminhos entre diferentes pontos.
